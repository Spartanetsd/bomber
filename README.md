# ІСКРА — вибуховий лабіринт

Аркада у стилі класичного бомбера для телефона й комп'ютера. Став бомби, підривай ящики, будуй ланцюгові вибухи, переможи всіх ворогів і знайди вихід, схований під одним із ящиків.

- Безкінечні рівні, 5 тем (Шахта, Крига, Джунглі, Неон, Попіл)
- 5 видів ворогів і 6 бонусів
- Сенсорне керування (джойстик + кнопка бомби), клавіатура на комп'ютері
- Збереження на початку кожного рівня, рекорд
- Працює без інтернету після першого відкриття

## Файли

Усі файли лежать в одній папці, без підпапок.

| Файл | Навіщо |
|---|---|
| `index.html` | уся гра: графіка, логіка, звук |
| `sw.js` | офлайн-режим |
| `manifest.json` | назва й іконка для «На початковий екран» |
| `apple-touch-icon.png` | іконка для iPhone |
| `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` | іконки для Android і браузерів |
| `README.md` | цей опис |

## Як опублікувати на GitHub Pages з iPhone

1. На github.com створи новий репозиторій, наприклад `iskra` (Public).
2. **Add file → Upload files** → вибери всі файли з цієї папки → **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main**, папка **/(root)** → **Save**.
4. За хвилину-дві гра відкриється за адресою `https://<твій-логін>.github.io/iskra/`.
5. У Safari: **Поділитися → На початковий екран**. Гра запускатиметься на весь екран і працюватиме офлайн.

## Як оновити

Заміни потрібні файли в репозиторії, а в `sw.js` зміни версію в рядку `const VERSION = 'iskra-v1';` (наприклад, на `iskra-v2`). Інакше телефон може ще якийсь час показувати стару копію з кешу.

## Керування

- **Телефон:** ліва зона — напрям (тримай заздалегідь — герой сам поверне на найближчому перехресті), права — бомба. Кнопка детонатора з'являється, коли є відповідний бонус.
- **Клавіатура:** стрілки або WASD, бомба — пробіл або X, детонатор — C, пауза — Esc.
